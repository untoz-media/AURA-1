# AURA Dataset v0.1

The first dataset will be designed around the capabilities AURA needs rather than simply maximizing dataset size.

## Planned categories

- General instruction following
- European Portuguese
- English
- Coding
- Reasoning
- Writing and rewriting
- General knowledge
- Tool-use patterns
- Assistant behavior

## Data requirements

Each training source should have documented provenance and an appropriate legal basis for use. Data should be cleaned, deduplicated and checked for sensitive or restricted content before entering the training set.

## Versioning

The first target dataset release is `AURA-Dataset-v0.1`.
