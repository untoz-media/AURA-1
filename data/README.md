# Data

This directory contains the datasets used during AURA-1 development.

## raw/

Original source data. Keep source provenance and license information alongside any imported material.

## processed/

Cleaned and training-ready datasets generated from the raw sources.

## Data policy

Do not add private, confidential, copyrighted or otherwise restricted material unless the project has a clear legal basis to use it for training and redistribution.

Large datasets and generated artifacts should not be committed directly to Git unless intentionally required. Use appropriate dataset hosting for large releases.
